# Scroll containers (scroll=horizontal, vertical or both): an axis's
# automatic minimum, a ratio's content floor and the extent, rendered
# with overflow hidden on the axes the node scrolls and clip on the
# other. The extent is the scrollable overflow: in-flow children's
# margin boxes with the end padding, and every border box below that no
# nested scroll container clips; start overflow is unreachable. A
# scroll container with content gives no extent: it scrolls its
# children, and the oracle renders its content as a child. Chrome
# takes each axis's floor on its own, an absolute ratio box's width on
# either axis. A flex item that scrolls only across its container's main
# axis is left out: Chrome keeps its content minimum there and Firefox
# does not, and the library follows Firefox (research 285).
# chrome 154.0.8037.57
